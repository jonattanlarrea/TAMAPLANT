SOBRE EL PROYECTO

Gemelo Digital para Monitoreo Inteligente de Plantas

🌱

Contexto del Proyecto

TAMAPLANT nace como respuesta a la creciente necesidad de optimizar el cuidado de plantas mediante tecnologías emergentes. En un mundo donde la agricultura urbana y el cuidado consciente de las plantas ganan relevancia, nuestro proyecto integra IoT (Internet de las Cosas), sensores inteligentes y visualización 3D para crear una experiencia de monitoreo inmersiva y en tiempo real.

Desarrollado como proyecto académico, TAMAPLANT combina hardware (ESP32) con una interfaz web moderna que permite a cualquier persona, desde aficionados hasta profesionales, monitorear las condiciones vitales de sus plantas de forma remota y eficiente.

🔭

Nuestra Visión

Democratizar la Tecnología

Hacer accesible la tecnología de monitoreo avanzado para cualquier persona interesada en el cuidado de plantas, sin necesidad de conocimientos técnicos complejos.

Sostenibilidad

Contribuir al cuidado responsable del medio ambiente mediante el uso eficiente de recursos hídricos y energéticos en el cultivo de plantas.

Innovación Continua

Evolucionar constantemente integrando nuevas tecnologías como machine learning para predicción de necesidades y automatización inteligente.

🎯

Objetivos del Proyecto

01

Monitoreo en Tiempo Real

Proporcionar datos precisos y actualizados de humedad del suelo, temperatura, pH y luminosidad mediante sensores IoT conectados a la nube.

02

Visualización Inmersiva

Crear un gemelo digital 3D interactivo que permita visualizar el estado de la planta y la ubicación de los sensores de forma intuitiva.

03

Alertas Inteligentes

Implementar un sistema de notificaciones que alerte al usuario cuando las condiciones de la planta se salgan de los rangos óptimos.

04

Accesibilidad Remota

Permitir el acceso desde cualquier dispositivo con conexión a internet, facilitando el monitoreo desde cualquier lugar del mundo.

05

Código Abierto y Educativo

Servir como referencia educativa para estudiantes y entusiastas de IoT, web development y agricultura inteligente.

Tecnologías Utilizadas

🔌

Hardware IoT

ESP32, sensores de humedad, temperatura (DS18B20), pH y luminosidad (BH1750)

🌐

Frontend

HTML5, CSS3, JavaScript (ES6+), Three.js para renderizado 3D

📡

Comunicación

WebSocket para transmisión de datos en tiempo real

🎨

Diseño

Interfaz futurista con temática cyberpunk y animaciones CSS
